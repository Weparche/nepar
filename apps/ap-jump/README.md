# AP Jump

Minimalistička satirična endless-runner browser igra za `https://lika.nepar.hr`.

## Kontrole

- `Space`, `↑` ili `W` — skok
- Tap/klik po canvasu — skok
- Rekord se sprema lokalno u browseru (`localStorage`)

## Stack

Čisti HTML + CSS + JavaScript + Canvas. Nema build koraka i nema vanjskih dependencyja.

## Cloudflare Pages

Za zasebni Pages projekt iz monorepa postaviti:

- Repository: `Weparche/nepar`
- Production branch: `main`
- Root directory: `apps/ap-jump`
- Build command: ostaviti prazno
- Build output directory: `.`
- Custom domain: `lika.nepar.hr`

## Napomena

Igra je politička satira i nije povezana s Andrejem Plenkovićem, Vladom Republike Hrvatske ni političkim strankama.
